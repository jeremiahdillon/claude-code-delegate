# Files matching these patterns are never sent to a delegated model
# (delegate-inference --files and delegate-agent --files).
#
# - A pattern without '/' matches the file name:        *.pem
# - A pattern with a leading '/' or '~' matches the full path:  ~/.ssh/*
# - A relative pattern with '/' matches that dir anywhere:      secrets/*
# - '*' also spans '/', so dir/* covers everything below dir.
# - A leading '!' re-allows a file an earlier pattern denied.
#
# Add to this over time. Note: this does NOT restrict what an OpenCode agent
# chooses to open on its own (delegate-agent runs stock plan/build permissions).
