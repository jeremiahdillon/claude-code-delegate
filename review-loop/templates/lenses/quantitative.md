- Recompute every figure the conclusions depend on, independently, in a temporary directory (a short script is fine). Report each mismatch with both values and your working.
- Can each figure be traced to an input: a source document, a cell, a stated assumption? Flag numbers that appear from nowhere.
- Do totals, subtotals and cross-references reconcile (parts sum to the whole, the same figure matches wherever it appears)?
- Check units, signs, periods, rounding, currency and percentage-vs-percentage-point errors.
- List the assumptions. Are they stated, reasonable and applied consistently? Which ones would change the conclusion if they moved moderately?
- For spreadsheets: formulas that don't match their neighbours, hard-coded values where a formula is expected, ranges that miss rows, cached values that disagree with the formula.
